# mpv_sponsorblock_minimal

This is a simpler version of the [mpv SponsorBlock plugin](https://github.com/po5/mpv_sponsorblock). This script only includes the sponsor skipping functionality. What is SponsorBlock? [Find out here!](https://sponsor.ajay.app/)

b toggles between on/off

A package for this script can be found in the AUR: [mpv-sponsorblock-minimal-git](https://aur.archlinux.org/packages/mpv-sponsorblock-minimal-git) (I don't maintain this)

## Dependencies
* curl (unless you download videos with --sponsorblock-mark)
* sha256sum (if you set sponsorblock_minimal-hash to "true")
